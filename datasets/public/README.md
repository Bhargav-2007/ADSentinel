# Official public validation dataset

This is the maintainer-published BloodHound CE Active Directory sample, exactly as downloaded. It is public sample/lab collector data, not private engagement data or proof of live Windows validation.

Source: https://bloodhound.specterops.io/get-started/quickstart/ce-ingest-sample-data

The archive is pinned/checksummed in bloodhound-sample-data/provenance.json. Collection filenames date from 2024-03-05; retrieved 2026-10-29. Licensing is recorded in source-licenses.md with the original Apache-2.0 text retained.

Object counts, reviewed controls, discrepancies and results are documented in validation/public-datasets/ and validation/performance/. Import never contacts sample domains.
